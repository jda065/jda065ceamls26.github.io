what_i_learned: |
 Today we focused on evaluating the performance of our machine learning models using RMSE and MAE. I calculated these evaluation metrics for both the training and testing data across the Random Forest, Support Vector Machine, and Extreme Learning Machine models. RMSE helped me understand how far the model's predictions were from the actual asthma values while placing more emphasis on larger errors, while MAE showed the average prediction error in a more direct way. Based on my results so far, the Extreme Learning Machine is currently my best-performing model for predicting asthma outcomes. We also focused on the difference between balanced and imbalanced data and how class imbalance can affect a machine learning model's predictions. We used SMOTE to balance the training data by creating synthetic examples for the underrepresented class, allowing the models to learn from a more balanced distribution of data. Comparing the balanced and imbalanced results helped me better understand how data preparation can directly influence model performance.
blockers: |
 One challenge I faced today was interpreting the differences between the training and testing RMSE and MAE values for each model. I had to focus on understanding what the scores actually meant instead of simply choosing the model with the lowest number. Another challenge was understanding how SMOTE changes the training data and determining whether balancing the dataset actually improved the model's ability to predict asthma outcomes. Comparing multiple models and multiple evaluation metrics required careful attention to make sure I was interpreting the results correctly.
