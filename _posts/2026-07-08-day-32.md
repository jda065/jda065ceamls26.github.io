Today I focused on analyzing K-fold cross-validation results using the original unbalanced asthma dataset. I evaluated my Random Forest, SVM, and Extreme Learning Machine models across multiple folds to better understand how consistently each model performed on different sections of the data. I compared RMSE and MAE values across the folds and examined how the models performed without using SMOTE to balance the dataset. This allowed me to compare the unbalanced cross-validation results with the balanced results from yesterday and better understand how class imbalance can affect model performance and reliability.

I had to carefully review the RMSE and MAE values for each model and focus on how consistent the results were across the folds. Understanding whether differences in performance were caused by class imbalance or the models themselves required more detailed analysis.
